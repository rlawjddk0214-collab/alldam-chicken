# 옳담치킨 공식 홈페이지

대학가 가성비 치킨호프 **옳담치킨**의 반응형 원페이지 홈페이지입니다.

## 메뉴
- 옛날통닭 9,500원
- 후라이드치킨 10,500원
- 양념치킨 / 간장치킨 11,500원
- 마늘치킨 12,500원
- 파닭치킨 13,500원
- 숯불치킨 10,500원
- 양념숯불치킨 12,500원

## 매장 정보 수정
전화번호, 주소, 네이버지도 링크가 확정되면 `script.js`의 `STORE` 값만 수정하면 됩니다. 현재 값은 임시값입니다.

## 파일
- `index.html` — 원페이지 홈페이지
- `style.css` — 반응형 디자인
- `script.js` — 전화번호/주소/네이버지도 설정

브랜드 메시지: **옳게 담고, 가격은 착하게.**
